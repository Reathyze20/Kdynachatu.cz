Kdy kdo jede — a kdo po kom.

Obrazovka, kde se chata plánuje: kalendář rezervací, založení pobytu a řetězec turnusu (kdo je teď → kdo pak → předání). Dnes jede kalendář jako měsíční mřížka a řetězec žije odděleně jen na Přehledu — redesign to má spojit na jedno srozumitelné místo.

Grounded v realitě (subagent zmapoval kód): měsíční mřížka Po–Ne, v buňce max 1 pruh + „+N", barva = kdo (z user.color), typ pevná / předběžná / záložní (záložní přiřadí server při kolizi). Založení je dnes matoucí dvoufázový klik (první klik jen filtruje). Řetězec „teď→pak" se z kalendáře vůbec nevyčte.

U každého dílu vidíš mobil i desktop a vybíráš A / B / C (A = nejjednodušší + doporučení).

Dané (nerozhoduje se tu): barva pruhu = kdo (z profilu), ikona = zvířátko · pole rezervace: termín, účel, kdo jede (spolucestující), poznámka, vzkaz pro dalšího, typ · dovolené se zobrazují jako tečky · každá rezervace zakládá zápis na nástěnce (ADR-0004, nenahrazovat kecací kanál) · minulé dny zamčené · kontrast ≥ 4,5:1. Ikony Lucide, bez emoji.
  1. U každého dílu zaškrtni „Tuhle chci". Můžeš zaškrtnout víc variant a do poznámky napsat, jak je spojit.
  2. Díl, na kterém ti nezáleží, nech prázdný — postavím doporučenou A.
  3. Volba se ukládá v prohlížeči, můžeš se vrátit. Nahoře přepínáš Světlé / Tmavé.
  4. Nakonec dole Zkopírovat volbu a vlož mi ji do chatu (nebo Stáhnout).
